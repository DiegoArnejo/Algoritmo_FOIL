# Algoritmo FOIL - Inducción de Reglas y Cálculo de FOIL Gain

Este repositorio contiene la resolución práctica de un caso de estudio sobre el algoritmo FOIL (First Order Inductive Learner), enfocado en la clasificación e inducción de reglas lógicas para un conjunto de datos de empleados en formación.

## Contenido del Proyecto

1. Ejercicio 1: Inducción de Reglas Lógicas
   - Identificación y separación de ejemplos positivos (`en_formacion == True`) y negativos (`en_formacion == False`).
   - Script en Python para extraer atributos y valores exclusivos de la clase positiva.

2. Ejercicio 2: Evaluación con FOIL Gain
   - Implementación en Python de la métrica FOIL Gain para evaluar la calidad de los literales.
   - Comparación matemática entre condiciones categóricas (`nivel_educativo == 'terciario'`) y numéricas continuas (`edad <= 23`).
   - Demostración y cálculo manual paso a paso de los logaritmos y ganancias obtenidas.
